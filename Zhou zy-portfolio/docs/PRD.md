## 1. 项目背景与目标

### 1.1 背景

个人作品集是设计师、前端开发者的「可交互简历」。它比 PDF 简历更能呈现审美判断、交互细节与代码实现能力，也更容易通过链接被分享给招聘方、潜在客户和同行。

本项目从零搭建一个可直接部署的静态作品集主页，一次性交付网页源码、视觉资源及三份项目文档，方便后续由人工或 AI 编程助手持续维护。

### 1.2 产品目标

1. 在 **10 秒内**让访客理解「我是谁、我做什么、我做得怎么样」。
2. 用 **4 个精选项目**展示从问题、方法到结果的设计与开发能力。
3. 提供低摩擦的联系方式，引导访客发送邮件或复制邮箱。
4. 建立有辨识度的个人视觉语言，避免模板化的作品集观感。
5. 在电脑与手机上均保持完整、顺畅、可访问的浏览体验。

### 1.3 成功指标（上线后验证）

| 维度 | 指标 | 目标值 |
| --- | --- | --- |
| 内容理解 | 首屏出现姓名/角色/价值主张 | 100% |
| 交互完整 | 导航、筛选、项目弹窗、复制邮箱均可用 | 100% |
| 响应式 | 320px—1920px 无横向滚动、无内容遮挡 | 100% |
| 性能 | Lighthouse 性能（桌面） | ≥ 90 |
| 可访问性 | Lighthouse 可访问性 | ≥ 95 |
| 可发现性 | 4 个项目详情均可从作品区进入 | 100% |
| 联系转化 | 访客可一键发邮件 / 复制邮箱 | 100% |

### 1.4 项目范围

**包含：**

- 单页作品集：首页 Hero、关于、作品、联系、页脚。
- 作品分类筛选与原生 `<dialog>` 项目详情。
- 移动端全屏导航。
- 复制邮箱、Toast 提示、上海本地时间。
- 轻量滚动显现、自定义光标、项目封面视差等氛围动效。
- 完整响应式与 `prefers-reduced-motion` 降级。

**不包含：**

- 后端接口、数据库、登录、支付。
- 在线表单提交与邮件服务器。
- CMS 或管理后台。
- 多语言切换（当前仅简体中文 + 英文点缀）。
- 访问统计与 Cookie 追踪。

## 2. 产品定位

### 2.1 一句话定位

> 一个带有独立杂志气质与实验性视觉的个人作品集，用真实可交互的网页呈现「前端开发 + 交互设计」的复合能力。

### 2.2 品牌关键词

- **Editorial**：大字号排印、非对称栅格、编号系统与衬线斜体。
- **Playful**：酸绿、钴蓝、橙红三色碰撞，贴纸与星号点缀。
- **Precise**：克制的动效、清楚的层级、完整的键盘与响应式支持。
- **Human**：第一人称叙述、工作原则、常驻城市与真实联系入口。

### 2.3 差异化

| 常见作品集 | 本项目 |
| --- | --- |
| 模板化卡片瀑布流 | 杂志式章节结构 + 强标题排印 |
| 只展示截图 | 封面为定制 SVG，项目详情说明问题/方法/结果 |
| 重动效、轻可用性 | 动效可降级、键盘可完成全部核心操作 |
| 依赖第三方库与字体 | 零依赖、零网络字体，可直接离线打开 |

### 5.2 页面级说明

#### 首页 Hero

- 目的：建立身份、审美印象与继续浏览动机。
- 关键信息优先级：`MAKE THE WEB FEEL ALIVE.` → 中文自我介绍 → 主 CTA → 数据。
- 右侧人物插画使用柔和旋转与贴纸；悬停时回正，形成「被拿起」的感觉。
- 主按钮指向 `#work`，次链接指向 `#about`。
- 页脚显示上海时区实时时钟，增强「真人、在线」的感受。

#### 关于

- 以「不是把页面做出来，而是把感受做进去」作为观点句。
- 数据概览使用大号衬线数字，建立节奏。
- 四张 bento 卡片分别回答：做什么、用什么、经历过什么、相信什么。
- 所有内容均为静态文字，方便搜索与 AI 维护。

#### 作品

- 深色背景与前后浅色章节形成强对比。
- 筛选按钮配套计数（全部 04 / 产品 02 / 品牌 01 / 实验 01）。
- 封面使用定制 SVG，围绕项目主题设计，不使用外部图库。
- 点击卡片打开详情；详情内容存放在 `<template>` 中，JS 仅负责克隆与展示，避免重复维护。

#### 联系

- 钴蓝色满屏区块，作为页面情绪高潮。
- 直接展示邮箱，减少表单摩擦。
- 「复制邮箱」仅作为辅助方式；主入口始终是 `mailto:`。
- 外链使用 `target="_blank"` + `rel="noopener noreferrer"`。

## 6. 交互说明

### 6.1 全局导航

| 操作 | 反馈 |
| --- | --- |
| 点击桌面导航 | 平滑滚动至章节；页头高度由 `scroll-padding-top` 预留 |
| 滚动页面 | 页头在 16px 后出现半透明毛玻璃背景；当前章节链接出现下划线 |
| 点击「聊聊合作」 | 跳转联系区，不弹出新页面 |
| 点击移动菜单按钮 | 全屏菜单淡入，背景滚动锁定，header/main/footer 进入 `inert` 状态 |
| 菜单内点击链接 | 菜单关闭、背景恢复可交互，并滚动到目标章节 |
| 按 Esc | 关闭移动菜单，焦点返回菜单按钮 |

### 6.2 作品筛选

1. 默认选中「全部」。
2. 点击任一分类后：
   - 其他按钮取消选中；
   - 当前按钮 `aria-pressed="true"`；
   - 不符合分类的卡片添加 `hidden`；
   - 符合条件的卡片播放一次 420ms 淡入上移动画；
   - 屏幕阅读器播报「已显示 XX，共 N 个项目」。
3. 分类结果不存在空状态，因为当前每个分类至少有一个项目；若未来分类无内容，应补充空状态提示。

### 6.3 项目详情

- 触发：点击任意项目卡片。
- 展示：原生 `<dialog>` 模态框，打开时锁定背景滚动。
- 内容：项目名、中文副标题、简介、封面、角色、类型、周期、技术、问题、方法、结果。
- 关闭方式：
  - 右上角「关闭」按钮；
  - 键盘 `Esc`；
  - 点击弹窗外的遮罩区域。
- 关闭后焦点返回触发卡片。
- 弹窗内部可独立滚动，最大高度受视口限制。

### 6.4 复制邮箱

- 优先使用 `navigator.clipboard.writeText()`。
- 非安全上下文、不支持，或权限被拒绝时，使用临时 `<textarea>` + `document.execCommand('copy')` 降级。
- 成功后按钮变为「已复制」，同时 Toast 提示邮箱内容；2.2 秒后恢复。
- 失败时 Toast 提示手动复制，不阻断用户点击邮箱链接。

### 6.5 动效与降级

| 动效 | 触发 | 降级策略 |
| --- | --- | --- |
| Hero 标题逐行上移 | 页面加载 | `prefers-reduced-motion` 下直接显示 |
| 滚动显现 | 元素进入视口 | 减少动态时直接显示 |
| 跑马灯 | 自动循环 | 减少动态时停止 |
| 卡片封面视差 | 指针在卡片上移动 | 触摸设备 / 减少动态时关闭 |
| 自定义光标 | 精确指针设备 | 触摸设备 / 减少动态时隐藏 |
| 项目弹窗入场 | 打开弹窗 | 减少动态时即时显示 |

## 7. 视觉与内容规范

### 7.1 色彩

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--paper` | `#F2EFE6` | 主背景、浅色文字 |
| `--ink` | `#12130F` | 主文字、深色章节 |
| `--acid` | `#D7FF5F` | 强调、按钮、贴纸、高亮 |
| `--orange` | `#FF5B35` | 次级强调、悬停、步骤编号 |
| `--cobalt` | `#2F4BFF` | 联系区背景、人物背景圆 |
| `--muted` | `rgba(18,19,15,.62)` | 辅助文字 |

### 7.2 字体

- 中文/无衬线：`PingFang SC`、`Microsoft YaHei` 等系统字体。
- 英文展示/衬线：`Bodoni 72`、`Didot`、`Georgia`、`Songti SC` 等本地字体。
- 技术标签/编号：`Cascadia Mono`、`Consolas` 等等宽字体。
- 不加载网络字体，避免 FOUT、隐私和可用性问题。

### 7.3 排版原则

- 标题使用超大字号与负字距，形成海报感；正文保持 14—17px、1.9 行高。
- 英文装饰与中文信息混排，英文只承担风格与节奏，不承载唯一关键信息。
- 辅助 mono 标签可小至 8—10px，但关键操作与正文不得依赖小字号。
- 内容宽度控制在约 60—75 个中文字符以内。

### 7.4 布局

- 桌面：12 栏网格，Hero 为 1.25fr / 0.75fr 两栏，作品区 7/5 + 5/7 错落。
- 平板：主要区块降为单栏，作品卡片全宽。
- 手机：单栏、全宽作品卡、横向可滚动的筛选条。
- 统一内容最大宽度 1440px，左右留白随视口缩放。

## 10. 非功能需求

### 10.1 性能

- 无第三方 JS/CSS 依赖，不发起网络字体请求。
- SVG 均为本地资源，开启原生懒加载（首张项目封面除外）。
- 首屏只加载头像、首张封面和必要 CSS/JS。
- 动画只改变 `transform` / `opacity`，避免触发布局抖动。
- 目标：桌面 Lighthouse 性能 ≥ 90，移动端 ≥ 85。

### 10.2 可访问性

- 语义化章节、标题层级、导航地标。
- 提供「跳到主要内容」链接。
- 所有功能支持键盘；焦点样式清晰可见。
- 装饰性 SVG 使用空 `alt` 或 `aria-hidden`；人物插画有描述性替代文本。
- 移动菜单打开时锁定滚动、限制焦点，并将 header/main/footer 置为 `inert`；关闭后恢复触发按钮焦点。
- 项目弹窗使用原生 `<dialog>`，自动获得焦点管理与 Esc 关闭能力。
- 颜色对比：主文字与背景对比度满足 WCAG AA（正文 ≥ 4.5:1）。
- 支持 `prefers-reduced-motion`。

### 10.3 兼容性

- 支持 Chrome / Edge / Firefox / Safari 最近两个大版本。
- 使用原生 `<dialog>`、`IntersectionObserver`、CSS 自定义属性等现代能力；不承诺 IE11。
- 可直接通过 `file://` 打开；也可部署到任意静态托管。

### 10.4 SEO

- 独立 `<title>`、`meta description`、Open Graph 基础标签。
- 使用语义化 `h1`（页面唯一）与 `h2/h3`。
- 添加 `Person` 结构化数据。
- 所有核心内容存在于 HTML 中，不依赖 JS 渲染，便于抓取。

### 10.5 隐私与安全

- 不采集访客数据、不设置 Cookie、不加载第三方追踪脚本。
- 所有外链使用 `rel="noopener noreferrer"`。
- 项目详情内容为本地模板，不使用不可信的 `innerHTML` 拼接。
- 邮箱公开可见，建议使用专用工作邮箱并开启反垃圾策略。

## 13. 风险与依赖

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 示例个人信息被误当作真实信息 | 品牌可信度 | 上线前按第 8 节替换；README 中标注示例内容 |
